2026, one story at a time

The newsroom publishes articles and a daily wire. This site is the other axis: time. Each month has a site, each story that is big enough gets a site of its own, and every one of them is built the same way, from sources captured, dated and hashed into a vault, with a status word on every claim. Start at a month, go down to a story, and come back up the same way.

Where this sits

Three levels, each a site with its own repository, version and release history: the newsroom, the year, the month, the story. Every level links up and down; nothing is reachable from only one direction.

Up

  • newsroom.sgit.ai: the SGit Newsroom: articles, the desks, the wire, the reading meter

Down

  • October 2026: the month's stories, with the PHP flaws as the lead
  • php2shell: the two PHP flaws of October 2026, tracked as evidence

How this site works

A hub site is one JSON file rendered by one script with no clock in it: the same data gives byte-identical pages. The gate checks links, twins, llms.txt, determinism and credential shapes before every release, and the release script refuses to call a release done until the live site serves the new version. The method is the one the story sites use, at the smallest size that still follows it.

2026.newsroom.sgit.ai is the SGit Newsroom's 2026, one site per month and one per story. Part of the SGit Newsroom and the sgit.ai network. Built by one editor and a team of software agents; the site is generated from data/site.json and never written by hand.
